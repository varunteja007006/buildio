# Buildio

This repository root is only a wrapper (README, LICENSE). All code lives in `buildio_pro/`, a pnpm + Turborepo monorepo.

- Run every command from `buildio_pro/`.
- Read and follow `buildio_pro/AGENTS.md` before working there — it is the authoritative instruction file for this repo.
- Per-package notes also exist in `buildio_pro/apps/eggsy/AGENTS.md`, `buildio_pro/packages/book-convex-backend/AGENTS.md`, and `buildio_pro/CLAUDE.md` (Convex usage rules).
